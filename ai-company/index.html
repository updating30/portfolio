1この会社のしくみ

社長が Claude Code アプリに日本語で頼むと、Claude が担当する社員の「役割ファイル」を読んで、その社員として仕事をします。社員は10人いて、それぞれ得意なことと仕事の手順が決まっています。

できたものは、このパソコンのフォルダに残ります。頼んだ仕事の進み具合や決めたことは、会社のフォルダの中の「台帳」（台帳.md）に1か所でまとめます。

台帳は、会社のフォルダの中の1枚のテキストファイルです。追加の道具やお金は要りません。会社ですでにタスク管理の道具（スプレッドシートやタスク管理ツール）を使っているなら、台帳の代わりにそちらに残す形にもできます。

覚えることは3つだけ

  1. 会社を開く
    アプリで ai-company のフォルダを開きます（2章）。
  2. 「〇〇に頼んで」と言う
    名前が分からなければ、やりたいことだけ言えば leader が振り分けます（3章）。
  3. 確認に答える
    公開・お金・削除の前には、必ず社長に確認が来ます（8章）。

2会社を開く

毎回この順番で開きます。開いたフォルダの中だけが「会社」になります。

  1. Claude Code アプリを起動
  2. 「Select folder」を押す
  3. 作業場のフォルダ
  4. ai-company
  5. 画面に ai-company と出たら準備OK

画面はアプリの版によって少し違って見えることがあります。位置ではなく、ボタンの文字を探してください。見つからない時は、スクリーンショットを撮って聞けば大丈夫です。

3頼み方は3通り

そのまま使える頼み方

writerに頼んで、こつこつの紹介文を書いてもらって
Instagramの投稿を1本作りたい
朝の報告をして

名前を書かずに頼むと、leader が「誰が・何を・どの順で」を決め、社長に一言伝えてから担当に回します。

4誰に頼む？早見図

左の「やりたいこと」から、右の社員をたどってください。

5仕事の流れ（どの社員も同じ）

社員は、いきなり作りません。先に質問と案が来て、社長のOKをもらってから作ります。緑で塗った所が社長の番です。

  1. 社長の番頼む
  2. 社員が質問するヒアリング
  3. 社長の番答える
  4. 案・構成を見せる
  5. 社長の番OKを出す
  6. 作る・点検する
  7. 成果物を置くmembers/〈社員〉/projects/〈仕事の名前〉/

質問への答えは、一度にまとめて返して大丈夫です。分からない所は「分からない」と答えてください。社員は推測で埋めず、空欄にして残します。

7何人かで組む仕事

複数の社員にまたがる仕事は、leader が順番と受け渡すものを決めます。たとえば LP は、writer → designer → lp の順に回ります。

8社長に確認が来る時

次の3つは、社員が勝手に進めません。必ず「中身を見せる → 社長が確認 → 実行」の順になります。

外に出さないもの

  • 社長の本名
  • 個人のメールアドレス
  • 本業（勤務先）の情報
  • APIキー

キーの扱い

APIキーは .env というファイルにだけ置きます。キーを作って貼るのは社長です。会話やほかのファイルには、キーを書かないでください。

9お金がかかること・かからないこと

Claude の Pro プラン・Gemini の無料枠・Canva の無料プランを前提に、追加のお金がかかるかどうかの一覧です（2026年10月時点）。

やること追加のお金・プラン
社員との会話・文章・調べもの・LP・教材づくり✓ なし　Claude の Pro プランの範囲
スクリプトを動かす（Python・ffmpeg）✓ なし　パソコンの中で動く
動画の文字起こし（Gemini）✓ なし　Gemini API の無料枠
画像を作る（Gemini）⚠ 課金が必要　Gemini API の課金設定（1枚 約0.039ドル〜）
Canva の「一括作成」⚠ プランが必要　Canva Pro 以上
Canva AI でデザインを作る✓ なし　無料プランは回数に上限（20回まで）
Canva のテンプレに文字を自動で流し込む⚠ プランが必要　Canva Enterprise
Instagram に投稿する✓ なし　投稿は人が行う

10朝の報告・夜の報告

leader が、台帳と各社員のフォルダを見て、5行以内で報告します。

朝の報告をして

→ 今日やること／各社員の進行中の仕事／社長の判断が要ること

夜の報告をして

→ 今日できたこと／できなかったこと／明日の一手

台帳の続きを、一緒に進めて

→ 台帳で進行中の仕事を読んで、続きを一緒に進めます。

11困った時は

社員として名乗ってくれない
「members/〇〇/CLAUDE.md を読んで、〇〇として動いて」と頼んでください。ai-company のフォルダが開いているかも確かめてください（2章）。
「画像は作れません」と言われた
Gemini API の画像の課金が設定されていないためです。課金を設定したら「キーが使えるか確かめて」と頼み、1枚だけ試します。
字幕の出るタイミングがずれる
Gemini の文字起こしは少しずれることがあります。video に伝えると、パソコンの中で動く無料の道具（faster-whisper、約500MB）を入れるか相談が来ます。勝手には入れません。
Instagram の原稿が「文字数オーバー」で止まった
そういう決まりです。テンプレの欄からはみ出す文字があると、CSV を作らずに止まります。原稿を短くして、もう一度。
本の文字が取れない
スキャンした画像だけの PDF は、文字を取り出せません。本の一覧（library/INDEX.md）に「文字なし」と出ます。
「混み合っています」と出た
Gemini が混んでいる時です。スクリプトは少し待って自動でやり直します。それでも駄目なら、時間をおいてもう一度。
できたものがどこにあるか分からない
成果物は members/〈社員〉/projects/ の中です。「〇〇の成果物の場所を教えて」と聞いても大丈夫です。
Instagram に投稿までしてほしい
投稿は社長がする決まりです。Instagram にはつないでいません。

1目的と範囲

目的社長の副業（AIで作ったツール・教材を届けて収益にする）のために、制作・リサーチ・執筆・動画・SNS を回す。
使う人社長（作者）1人。非エンジニアでも、アプリに日本語で頼むだけで使える作りにした。
事業の前提製造現場×AI（例：装置トラブル対応エージェント）／初めての人向けの教材（例：50代向けの GitHub 実務講座）／スマホアプリ（例：習慣トラッカー「こつこつ」）／Instagram 運用
扱わないこと案件の受注（クラウドワークスなどへの応募・納品）。別の仕組み「AI社長」の担当。
仕事の状態会社のフォルダの 台帳.md に1か所でまとめる（頼んだ仕事・進み具合・決めたこと）。会社で使っているタスク管理の道具があれば、そちらに置く形にもできる。
公開の方針外に出すのは「見せる用」（モック・サンプル・資料）だけ。コード本体は公開しない。

2全体の構成

このパソコンの中にあるもの（アプリ・会社のフォルダ・道具）と、インターネットの先にあるサービスに分かれます。

部品役目どこにあるか
Claude Code アプリ社長の頼みを受け、役割ファイルを読んで社員として動く。ファイルの読み書き・スクリプトの実行もする。このパソコン（デスクトップアプリ）
会社のフォルダルール・社員の役割・成果物・設定の置き場。作業場の中の ai-company/
道具スクリプト4本を動かす（字幕の焼き込みには ffmpeg）。Python 3.14・ffmpeg（このパソコン）
台帳（台帳.md）頼んだ仕事・進み具合・決めたことを1か所にまとめる。leader の報告のもとになる。会社のフォルダの中

3ルールの重なり

ルールは3段の入れ子です（作業場＝作者が AI と働くための作業フォルダ全体）。外側ほど優先され、食い違ったら外側に従います。

4フォルダの構成

どの社員のフォルダにも、CLAUDE.md（役割）・inbox/（依頼メモ）・projects/（成果物）の3つがあります。下の木では、それ以外に持っているものだけを書いています。

  • ai-company/
    • CLAUDE.md会社のルール（社長の事業・10人の一覧・頼み方・共通ルール）
    • README.mdフォルダの地図と動かし方
    • 台帳.md仕事の状態（頼んだ仕事・進み具合・決めたこと）を1か所にまとめる
    • config.yaml設定（画像のモデル・文字起こしのやり方など。キーは入れない）
    • .envAPIキー（社長が貼る。使うのは GEMINI_API_KEY だけ）
    • .gitignore外に出さないものの一覧
    • .claude/Claude Code の許可の設定
    • members/
      • leader/統括（追加のものは無し）
      • brunson/books/（本のPDF）・library/（テキスト化した本と INDEX.md）・tools/pdf_to_md.py
      • designer/scripts/compare_images.py
      • lp/PASONA と10原則は CLAUDE.md の中
      • video/scripts/burn_subtitles.py
      • researcher/recipes/（調べ方の型4本）
      • writer/reference/（セールス辞書6本）
      • analyst/（追加のものは無し）
      • product/guides/（構成の4型・デザイン参考）・templates/base.html
      • sns/scripts/canva_bulk_csv.py・templates/carousel_basic.yaml

9共通ルール

話し方

日本語・敬語。brunson だけは、くだけた丁寧語で本音を話す。

置き場

依頼のメモは inbox/、成果物は projects/〈仕事の名前〉/。仕事が終わったら inbox を空にする。

確認が要る3つ

外への公開・送信・投稿／お金がかかる操作／ファイルの削除・上書き。必ず「提示 → 社長の確認 → 実行」。

外に出さない4つ

社長の本名・個人のメールアドレス・本業（勤務先）の情報・APIキー。

キー

.env にだけ置く。キーの作成と貼り付けは社長がする。

作らない

実績・数字・お客様の声をつくらない。無いものは「ねらい」「見本」と書くか、空欄にして社長に聞く。

推測しない

分からないことは推測せず、社長に聞く。

公開の方針

外に出すのは「見せる用」だけ。コード本体は公開しない。

10前提と制約

使い始める前に知っておくことです（2026年10月時点）。

✓ 追加のお金なし

  • 社員としての会話・リサーチ・執筆・LP・教材・分析・報告（Claude の Pro プランの範囲）
  • 字幕：文字起こし（Gemini API の無料枠）から焼き込みまで
  • Instagram 原稿の CSV 作り・本のテキスト化（パソコンの中だけで動く）

⚠ 課金・プランが必要

  • 画像の生成：Gemini API の課金設定（1枚 約0.039ドル〜）
  • Canva の一括作成：Canva Pro 以上
  • Canva のテンプレへの自動の流し込み：Canva Enterprise

― 知っておくこと

  • Gemini の文字起こしは、字幕の出るタイミングが少しずれることがある（パソコンの中で動く faster-whisper に切り替えられる）
  • Gemini が混んでいる時（503）は、自動で待ってやり直す
  • Instagram への投稿・外への公開は人が行う
  • X検索・Slack通知・Figma はつないでいない
