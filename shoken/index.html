通知表所見作成アシスタント

学年・教科・学期と、児童のエピソードを入れると、AIが所見の案を3つ出します。先生は案を選んで手を入れるだけ。「案2をベースに…」と頼めば、会話で直せます。下の画面で、例を選んで「所見を生成する」を押してみてください。

実際のツールのしくみ

Python（Streamlit）と Claude API で作ったWebアプリです。コードは公開していません。

2週間 → 1日1クラス約40名分の所見づくり

現役の教員に提供し、実務で使われています。一人ひとりに合った表現で案が出るので、手を抜くどころか「以前より一人ひとりに合った所見が書けるようになった」との声をいただきました。

現場のルールを守る

  • 低・中・高学年で文体を書き分け
  • 道徳は「できました」などの能力評価を使わない
  • 総合は探究の過程（課題→調べる→まとめ）を書く
  • 後期・学年末は指導要録向け：4要素・180〜200字・「〜くれました」を使わない

選んで直せる形で出す

  • 性格の違う3案（バランス型／意欲・プロセス重視／学びの深化・変容重視）
  • 文字数の目安と、要注意の言い回しを画面で知らせる
  • 「案2をベースに…」と会話で直せる
  • 結果をテキストで保存できる

使い続けられる工夫

  • 先生が選べるキャラクターが、いっしょに考える
  • AIの答えの形が崩れても、案を拾える読み取り
  • 合言葉で入口を閉じて、Web上で使える
  • 学年・教科を変えたら、会話をリセット
