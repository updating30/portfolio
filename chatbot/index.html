見積もりの流れ

お見積もりは無料です。図面がなくても、手書きのスケッチや現物からご相談いただけます。

  1. 図面を送るフォームから図面（PDF・DXF・STEP・IGES）と、数量・材質・希望納期を。先にNDAも結べます。
  2. お見積もり担当者が図面を確認し、2営業日以内を目安にお送りします。
  3. 加工・検査試作は5〜7営業日、量産は2〜3週間が目安。三次元測定機で検査します。
  4. 出荷宅配便・チャーター便で国内へ。検査成績書もお付けできます。

作品の説明

この見本について：ホームページに埋め込むAIチャットボット

中小企業のホームページに、その会社の資料を覚えさせたAIチャットボットを置き、よくある質問への答えと、見積もり依頼・担当者への橋渡しを24時間行う仕組みの見本です。架空の町工場「アオバネ精工」を1社目のお客様に見立てて、本番と同じ手順で作りました。

仕組み

ホームページ右下のチャット。Dify が出す埋め込みのコードを1か所に貼るだけで置ける
→
Dify会社の資料（会社概要・設備・見積もりと納期・よくある質問・答えないこと）と、答え方の決まり（システムプロンプト）を持つ
→
Claude（Anthropic）資料から関係する所を引いて、出典つきで答える
→
担当者へ分からないこと・約束が要ることは、フォームと電話へつなぐ

今は、AIを動かさずに、本番で返すべき答えを用意して表示しています（動きの見本）。本物の Dify につなぐ時は、ページの中のトークン1か所を差し替えます。

ボットに守らせていること

  • 強度・公差など、技術的にできるかを言い切らない（図面を見て担当者が判断）
  • 価格・納期は目安だけ。約束はしない
  • 図面やデータをチャットで受け取らない（フォームから。NDAも案内）
  • 海外への発送・海外の引き合いは、可否を言わず担当者へ
  • お名前・連絡先を尋ねない。書き込まれても、くり返さない
  • 他社の名前を出して比べない。最初の返事で、AIであることを伝える

#質問確かめること

受注したら、同じ流れで御社のホームページに

  1. ヒアリングと資料集め（ホームページ・パンフレット・料金表・よくある質問・答えてほしくないこと）
  2. 資料を整えて Dify に入れ、答え方の決まり（禁止表現・業界の注意点）を作る
  3. テスト会話で確かめ、直す
  4. ホームページに埋め込む（WordPress などにも対応）
  5. 毎月、会話の記録から「答えられなかった質問」を拾い、資料と決まりを直す改善の提案

Dify と Claude の利用料は、お客様の名義のアカウントから直接お支払いいただく形にしています（こちらで立て替えたり、上乗せしたりはしません）。
