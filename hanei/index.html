この進め方で、できること

反映を任せていただく時に、担当チームが安心できる3つの仕組みです。

止まった項目に、理由と次の一手

反映したのに未実施なら、原因を調べて直します。触れないサイトは、制作会社への依頼文にします。管理者の画面の表を見るだけで、どこで、なぜ止まっているかが分かります。

前後の記録で、元に戻せる

作業の前の状態を写してから変えます。指示書と食い違う以前の設定は、消す前にお客様に確かめます。ログインの情報は、記録に書きません。

手順書と時間で、次の月を速く

作り方ごとの手順とつまずき、1社あたりの時間が残ります。6時間目からの件数と時間を、数字をもとに決められます。

3分で体験する

まずはこの3つだけ。くわしい使い方と、分からない言葉の説明は、下の「くわしい使い方」にあります。

  1. 「作業台」のタブを開き、青いボタンを上から順に押す右の窓（お客様のサイトとファイル）が、押すたびに変わります。
  2. 判定で「未実施」が出たら、原因2つを直して、もう一度確かめる置いた場所を直し、以前からの設定はお客様に確かめてから消します。
  3. 「管理者の画面」のタブで、変わった所を見る実施済みの数・表・時間の棒・手順書のつまずきが変わっています。

作業台の8つの手順
  1. 「作業台」のタブを開く（この画面の 作業台をはじめる でも開けます）。段1に、指示書の3項目と、AIが分けた段取りが出ます。
  2. 段取りを確かめた。作業の前を記録する → 段2に、作業の前の記録が5つ並びます。右の窓で見る ▸ で、窓がそのファイルに切り替わります。
  3. 指示書どおり反映する → 窓のサイトに「よくある質問」と、右下の「AIに質問する」が出ます。窓の「作業の前／作業の後」で見比べられます。
  4. 管理画面の判定を確かめる → ファイル2つが ！ 未実施。調べて分かった原因が2つ出ます。
  5. 原因1の 最上位に置き直す → 窓の llms.txt の置いた場所が、最上位になります。
  6. 原因2の お客様に確かめる文面を見る → 読んだら お客様から『消してよい』と返事が来た（見本）（文面を開くまで押せません）。窓の robots.txt で、以前の2行が赤の −、足した行が緑の ＋ になります。
  7. もう一度、判定を確かめる → 3項目とも ✓ 実施済み。上のタブ「管理者の画面」に「更新あり」の印が付きます。
  8. 段5の記録・時間・報告の下書きを見て 報告を担当チームに回す（見本） → 終わりのカードの 管理者の画面を見る で、変わった所へ移れます。

作業台のほかの見方
  • 右の窓のタブ（サイトの画面・robots.txt・llms.txt・よくある質問のHTML）で、見る物を切り替えられます。
  • 終わった段は自動でたたまれます。段の中の「中を見る」で開き、「たたむ」で閉じます。
  • 反映の後、窓のサイトの右下の「AIに質問する」→ 質問の札を押すと、よくある質問から答える小さな窓が開きます（決まった答えを出すだけで、AIにはつながっていません）。
  • 作業台の下の「触れないサイトは、制作会社への依頼文」では、依頼文の「写す」で文をコピーできます。
  • 窓の「よくある質問のHTML」では、View（Webでの見え方） で、Webで開いた時の形と、検索やAIが読み取る中身を見られます。
  • 基本はボタンを押すだけですが、必要な時は各段の ＋ この段にメモを書く（任意・手入力） で、その段の覚え書きを残せます（段5の記録と報告に入ります）。お客様への文面と報告は、✎ この文面を直す（手入力） で文そのものを書き換えられます。
管理者の画面の見方
  • 表の項目の札（実施済み・返事待ちなど）を押すと、その会社の作業台の詳細が開きます。上の ← 管理者の画面に戻る の1回で、押した札に戻れます。
  • 表の上の「返事待ちだけ（2社）」で、止まっている会社だけになります。
  • 会社名の下の「前後の記録を見る」で、その会社の作業の前・作業の後・確かめた日時が開きます（つばめ精機以外の4社）。
  • 時間の棒にマウスを当てると、段階の名前と分が出ます。6時間目からの続け方は「案」で、数字は架空の5社で組んだ目安です。
  • 手順書は、4つのタブ（WordPress・ホームページ作成サービス・制作会社が管理・Googleビジネスプロフィール）で切り替えます。

  • 作業台の最後の「終わりのカード」の「最初からやり直す」
  • ページを開き直す。何も保存されないので、何度でも初めから試せます。
